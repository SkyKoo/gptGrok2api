# GPT Image 原生蒙版

`POST /v1/images/edits` 和 `POST /api/image-tasks/edits` 均支持可选 `mask`，同步/异步、JSON/multipart 使用相同校验。只支持 GPT Image 模型。当前仅开放已验证的一张原图配一张蒙版，多参考图带蒙版会返回 400，不猜测蒙版对应哪张图。

## 请求

Multipart 在原编辑请求上增加 `-F 'mask=@mask.png;type=image/png'`。`mask[]` 兼容别名也接受，但只能出现一份蒙版，重复字段或文件和值同时传入会被拒绝。

JSON 使用 `"mask": "data:image/png;base64,..."`，也接受纯 Base64、HTTP(S) 图片 URL 或 `{ "image_url": "https://..." }` / `{ "b64_json": "..." }` 单引用对象。不支持文件 ID、数组或多个引用。URL 沿用参考图的远端地址与重定向检查，不转发调用方鉴权头，最大下载 4 MiB、30 秒。`mask` 省略或为 `null` 时不启用蒙版；空字符串、空文件不会静默退化为普通编辑。

蒙版必须为可完整解码的 PNG，不超过 4 MiB、3200 万像素，宽高与原图文件完全一致。Alpha=0 表示编辑区域，Alpha=255 表示保护区域；至少有一个完全透明的像素。拒绝只画了黑白色但没有透明选区的普通不透明图片。不根据文件名或声明的 MIME 判断真实格式。

校验错误返回 `400 invalid_request_error`，并标记 `param: "mask"`；发生在账号分配及异步任务接受之前。外部下载地址和图片内容不写入错误。

## 上游适配

原图按既有方式上传。蒙版通过 Alpha 转为不透明灰度 PNG（透明选区为黑色、保护区域为白色），再使用 `use_case=dalle_agent`、`entry_surface=image_edit_mask`、`store_in_library=false` 单独上传。消息中的 `metadata.dalle.from_client.operation` 使用 `type=inpainting`、`original_file_id`、`mask_file_id`。

蒙版不占参考图附件位置，不成为普通提示图片，也不混入生成结果。每次调用及每个并发输出独立持有上游文件 ID，不能跨账号复用。没有蒙版的请求不上传蒙版、不写入选区操作元数据。

## 异步、兼容与数据

蒙版字节参与 owner 范围内的请求摘要：同一个 `client_task_id` 配不同蒙版，或从有蒙版改为无蒙版，返回 409；相同请求只返回原任务。未带蒙版的旧摘要保持兼容。已接受任务保存摘要，蒙版和原图字节仅留内存，终态释放；不会把 Base64、远程 URL 或蒙版写入任务文件及公共任务响应。

继承既有重启策略：在途任务重启后标记中断，不重放生成；已完成任务仍可查询。同请求重放返回保存的结果/错误，避免二次生成。没有数据库迁移或新增配置。回退前应等待在途蒙版任务终结；旧版仍能读取终态结果，但重新提交带蒙版的请求会被旧版拒绝。

## 扩图边界

蒙版是可选的编辑能力，不与扩图自动绑定。Lumora 第一版扩图按原图、目标构图和扩展提示交给 AI 完整生成，**不传 `mask`**，不做原图贴回及接缝后处理。本次仅接通 CFM 蒙版，Lumora 扩图页面另行实现。

上游支持蒙版不等于严格锁定原图像素，也不保证实际输出尺寸与请求相同。2026-10-10 的隔离真实测试验证了同图同提示词、只改左右蒙版时编辑区域随之改变；本次正式代码通过本机模拟上游测试验证传输、校验、任务重放及无蒙版兼容，不重复消耗真实生图额度。
