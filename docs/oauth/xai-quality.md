# xAI OAuth 的 grok-4.7 降智风险检测

新授权、手动设备码和凭据导入在上传 CPA 前检测 `grok-4.7`。只有当前版本、24 小时内
全部通过的结果允许上传；检测失败保留授权和凭据，账号行显示原因，可以单独复测。
检测使用账号的 Build 额度。

## 检测依据

参考 [kaibush/grok-iq](https://github.com/kaibush/grok-iq/tree/5a26645f53db7bdf3b2f0f4775969f132d347018)
的固定账号检测、指令遵循标记、多轮复核和证据留存。CFM 使用 `grok47-v1` 规则：

- 每组 3 道动态题：库存变化、任务并行依赖、整除计数。答案由程序计算，
  提示词不提供答案，每题带随机校验标记，避免固定输出或缓存直接通过。
- 第一组出现失败，或正在复测已被拦截的账号，再用新参数、新标记执行第二组。
- 两组各至少 2 道题失败：标记“降智风险”，阻止同步并尝试移除对应 CPA 凭据。
- 有失败但不足上述门槛：标记“疑似降智”，阻止新交付，保留现有 CPA 凭据。
- 全部通过：标记“检测正常”。风险账号需要两组共 6 题全部通过才能解除拦截。
- HTTP 错误（包括 401/402/429）、网络错误、响应未完成、缺少最终文本、模型未明确
  返回 `grok-4.7`，都属于“检测失败”，不判为降智。失败也不会清除已有风险。

保存题目、程序答案、模型最终输出、判断依据、耗时、输出 Token 和可选思考 Token。
未报告思考 Token 不等于其值为 0。CPA 管理调用会缓冲响应，无法提供可靠的真实生成
速度，因此不直接复用 GrokIQ 的 TPS 阈值，也不依据思考 Token 为 0 自动删除。

这是有限题目的答案质量和指令遵循检测，不证明官方替换了模型，也不保证通过账号
在其他任务中不会出现质量下降。阈值尚未以真实 grok-4.7 正常/异常样本校准；本地回归
验证检测及处置流程，不能替代上线前的小规模真实样本验收。

## 凭据归属与 CPA 移除

未交付凭据使用当前 Access Token，沿账号日常代理请求 xAI；检测本身不刷新 Token，
不查询旧 billing。已交付或交付结果未知的账号通过 CPA 管理接口检测：

1. 使用原 CPA 连接及交付文件名查询 `GET /v0/management/auth-files?name=…`，
   核对文件名、`provider/type=xai`、邮箱和唯一 `auth_index`。
2. 调用 `POST /v0/management/api-call`，传入该 `auth_index` 和 `Bearer $TOKEN$`；
   CPA 替换当前 Token、负责必要续期及账号代理。不经过公共模型端点负载均衡，
   不下载 Token 到 CFM，也不使用本地旧副本续期。
3. 先将风险及移除目标写入加密 OAuth 存储，再核对原 CPA 地址、文件名、provider、
   邮箱、auth_index，调用 `DELETE /v0/management/auth-files?name=…`。
   不调用全量删除，不扫描删除其他同邮箱文件或其他 CPA 的副本。
4. 回读确认文件消失才记为“已移除”。接口不支持、权限不足、身份变化或结果不明，
   标记“待人工处理”，显示 CPA 名称、文件名、原因，提供“重试移除 CPA”。

本机 CPA 源码 `7cad1cb7df48c6c5ffb7ff0b34ef8198806115bc` 实现了上述管理接口。
其他部署版本不支持指定账号调用时，检测失败；不退回使用 CFM 旧凭据。

重新授权不会清除风险；若新授权确认风险，也核对并处理原目标中同账号的旧 CPA 文件。
已移除的托管凭据不会由本地旧副本补传；应重新授权/导入新凭据，复测通过后交付。
删除 CFM 本地账号记录本身仍沿用原有行为，不等于删除 CPA 凭据。

## 定时检测

xAI OAuth 页面提供开关、间隔、队列数量、最近检测和下次到期时间。默认开启，每个
账号每 24 小时检查一次，可设 1–168 小时。首次上线后，未检测的现有账号逐个入队。
正常和检测失败的账号都按上次完成时间计算下一周期；有质量任务排队/运行时，
自动调度不继续堆积任务。

配置保存在注册控制面的 `grok_quality_schedule`；时间和结果保存在加密 OAuth 账号中。
重启保留周期和标记。禁用、授权中、正在执行其他 OAuth 操作的账号会跳过；
已从 CPA 移除且仍为托管旧副本的账号不再定时调用。维护/发布暂停时不新增任务。
关闭定时检测不关闭交付前检测，也不取消已入队任务。

“检测已有账号”立即提交当前页面所限定的账号（最多 500 个），账号行支持单独复测。
定时检测不主动重新上传任何凭据；解除风险后通过账号行处理交付。

## 验证范围

Go 模拟 xAI/CPA 验证判分、0 思考 Token、SSE、交付拦截、指定账号调用、旧凭据零续期、
风险先保存再删除、目标变化拒绝删除、删除回包丢失与人工回退、重授权保留风险、
调度配置持久化与任务去重。Node/Vue 和隔离 Chromium 检查筛选、检测详情、风险操作、
周期保存及移动端布局。测试没有检测线上账号，也未删除真实 CPA 凭据。
